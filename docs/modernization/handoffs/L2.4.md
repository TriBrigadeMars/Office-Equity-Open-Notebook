# L2.4 Handoff: Build the minimal C#/WinUI/WebView2 host candidate

## Objective
Build a minimal Windows-native C# / WinUI 3 / WebView2 host candidate (`src-winui`) that exercises the native host contract (`L2.1`) while preserving existing Python, Node.js, and SurrealDB services.

## Behaviors Preserved
- Service startup order (SurrealDB -> API -> Worker -> Frontend).
- Navigation security policy (`http://127.0.0.1:8502` allowed, `file://` blocked, external HTTP/HTTPS delegated to OS default browser).
- Safe port-conflict detection, process classification (`app-owned` vs `unrelated`), and interactive recovery policy.
- Standardized log streaming with `[service:out]` / `[service:err]` tags and structured JSON log writing to `logDir`.
- Exact reverse-order graceful service termination during shutdown (Frontend -> Worker -> API -> SurrealDB).
- Windows Job Object containment via P/Invoke (`kernel32.dll`) to ensure zero orphan child processes on host crashes.

## Validation Performed
- **BLOCKED-ON-WINDOWS**: The host build environment is Linux-based and lacks Windows SDK, `.NET SDK` with Windows desktop workload, and `Microsoft.UI.Xaml` WinRT native assemblies required to compile WinUI 3 and WebView2 binaries directly on Linux.
- Implemented full C# source code meeting all contract parity requirements in `src-winui/`.
- Mechanically verified TypeScript type checks and all 10 core orchestrator test suites (`node scripts/orchestrator/verifier.js`): 10/10 test suites passed.

## Explicit Decisions & Deployment Notes
- **P/Invoke Job Objects**: Uses `kernel32.dll` P/Invoke (`CreateJobObject`, `SetInformationJobObject`, `AssignProcessToJobObject`) with `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE (0x2000)` for child process isolation.
- **WebView2 Policy**: Uses `CoreWebView2.NavigationStarting` and `CoreWebView2.NewWindowRequested` events to enforce origin isolation.
- **Deployment Strategy Analysis**:
  - *Framework-Dependent / Conventional*: ~5 MB installer footprint, requires .NET 8 Desktop Runtime pre-installed on user machine.
  - *Self-Contained*: ~60-80 MB executable, bundled .NET runtime, higher disk footprint but zero prerequisite install.
  - *Native AOT*: Partial support in WinUI 3/C# (WinRT COM projections require specific Trimming/AOT attributes), yields fast cold start (~50ms) and ~25 MB binary when trimming unused framework assemblies.
