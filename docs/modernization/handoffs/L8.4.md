- **Desktop Shell UI:** Native Tauri host (`src-tauri`) as primary; legacy Electron shell retained as audited fallback binary in packaging configuration.

## 4. Canary Release & Rollback Triggers

- **Crash Spike Trigger (`CANARY_TRIGGER_CRASH`):** Crash rate > 0.5% in 1 hour -> Automatic rollback to stable release binary.
- **API 5xx Trigger (`CANARY_TRIGGER_HTTP_5XX`):** Gateway proxy 5xx rate > 1.0% over 15 minutes -> Automatic rollback of reverse proxy routing rules.
- **Startup Failure Trigger (`CANARY_TRIGGER_STARTUP_FAIL`):** Cold start failure rate > 1.0% -> Fallback safe mode prompt.
- **Memory Leak Trigger (`CANARY_TRIGGER_MEMORY_LEAK`):** RSS memory > 500MB for > 5 minutes -> Throttle canary and force worker child recycling.
