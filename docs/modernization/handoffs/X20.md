# X20 Handoff: Remove Bundled Node.js — NON-LOCAL

**Completed:** Yes  
**Packet ID:** `X20`  
**Execution Class:** GEMINI (NON-LOCAL) — Gemini 3.1 Pro / 2M tokens  
**Master-Plan Source:** `20 / Workstream 12; External Gate X19–X20` (`MASTER_MODERNIZATION_AND_EFFICIENCY_PLAN.md`)  

---

## Objective
Eliminate the bundled Node.js runtime and Next.js standalone server (`server.js`) from the desktop execution path now that native frontend static asset serving, API reverse proxying, and unbuffered SSE event streaming are verified in the native host (`src-tauri`).

---

## Deliverables & Architectural Changes

### 1. Removal of Node.js Runtime Dependencies
- **Runtime Preparation (`scripts/prepare-runtime.js`):** Removed `buildNode()` download and extraction step, `NODE_VERSION` pin, and `node` checksums. Updated `buildFrontend()` to assemble pure static frontend assets into `runtime/frontend/static`.
- **Runtime Manifest (`src/contracts/runtime-manifest.ts`):** Removed `node/node.exe` from optional bundle paths and replaced `frontend/server.js` requirement with `frontend/static` in `REQUIRED_RUNTIME_PATHS`.
- **Packaging & Installer (`scripts/package.js` & `scripts/build-installer.js`):** Removed `node/node.exe` and `frontend/server.js` from packaging requirements and eliminated `SecNode` (Node.js runtime) from the NSIS installer script.
- **Desktop Launcher (`main.js`):** Updated runtime verification requirement from `frontend/server.js` to `frontend/static`.

### 2. Service Table & Service Lifecycle (`src/contracts/service-table.ts` & `scripts/start-services.js`)
- **Node Service Removal:** Removed the `frontend` service entry (`command: 'node', args: ['server.js']`) from `SERVICE_TABLE`. The service table now manages exactly 3 backend services (`surrealdb`, `api`, `worker`).
- **Native Host Ownership:** Port 8502 (frontend static assets & API proxying) is owned directly by the native embedded server (`src-tauri`). `scripts/start-services.js` no longer resolves or spawns `node.exe` / `server.js`.

### 3. Performance & Benchmark Metrics (`src/contracts/performance-harness.ts`)
- **Node Runtime Footprint:** `nodeRuntimeBytes` reduced to **0 B** (down from 56 MB on disk).
- **Validation Rules:** Updated benchmark validator to accept `nodeRuntimeBytes >= 0`.

## Rollback Procedure
If a regression requires returning to the bundled Node.js runtime prior to release acceptance:
1. Re-add `node/node.exe` step and `NODE_VERSION` to `scripts/prepare-runtime.js`.
2. Restore `REQUIRED_RUNTIME_PATHS` in `src/contracts/runtime-manifest.ts` to include `frontend/server.js`.
3. Re-add `frontend` service entry to `SERVICE_TABLE` in `src/contracts/service-table.ts`.
4. Restore `SecNode` section in `scripts/build-installer.js`.
