## Summary of Findings

### 1. Architectural Overview
The current Open Notebook desktop application runs a Next.js standalone server (`server.js`) on `http://127.0.0.1:8502`. It handles two core functions:
1. **Serving Frontend UI & Assets:** Hydrating React components and serving static scripts (`.next/static/*`).
2. **Reverse Proxying Backend Requests:** Forwarding all `/api/*` HTTP traffic to the FastAPI backend on `http://127.0.0.1:5055` (`INTERNAL_API_URL`).

### 2. Server-Only Feature Audit
- **Server Components:** **0** (All page routes operate as React Client Components using client-side fetching).
- **Server Actions:** **0** (All mutations go through explicit FastAPI REST calls via TanStack Query / `fetch`).
- **Next Middleware:** **None** (`middleware.ts` / `middleware.js` is NOT used).
- **Next Route Handlers:** **None** (All API routes are proxied directly to FastAPI via Next.js `rewrites()`).
- **Filesystem / Server DB Access in Frontend:** **None** (All persistence is delegated to FastAPI + SurrealDB).

Conclusion: The frontend UI is **100% decoupling-ready** for static export (e.g. Vite or static Next export).

## Desktop-Specific Rewrite & Proxy Responsibilities

1. **Loopback Single-Origin Proxy:**
   Next.js binds to `127.0.0.1:8502` and rewrites `/api/*` to `127.0.0.1:5055`. This unifies UI and API under a single origin, avoiding CORS issues in WebView.
2. **Unbuffered SSE Pass-Through:**
   Chat completion (`/api/chat/stream`) requires real-time chunked token streaming (`text/event-stream`). Proxy layers must disable buffering (`X-Accel-Buffering: no` or immediate flush).
3. **Multipart Body Pass-Through:**
   Document uploads (`/api/sources/upload`) send binary multi-megabyte payloads. The proxy must pass streams through without payload truncation or memory buffering.

## Dependencies & Blocker List

### UI Dependencies (Preserved)
- React 18/19, Zustand, TanStack Query (React Query), Tailwind CSS, Lucide Icons, react-markdown.

### Server-Runtime Dependencies (Candidates for Removal in Section 19)
- Bundled Node.js runtime (~95MB).
- Next.js standalone server process (`server.js`).
- Server environment variables (`INTERNAL_API_URL`, `PORT`, `HOSTNAME`).

### Blockers to Static Build & Migration Plan
1. **[BLOCKER-01] Absence of Node.js Reverse Proxy for `/api/*`:**
   - *Impact:* Static client build cannot route `/api/*` to FastAPI without a proxy server or CORS enablement.
   - *Resolution:* Migrate reverse proxying to the selected native host (Rust / Tauri in `X19`).
2. **[BLOCKER-02] SPA Client Routing Fallback:**
   - *Impact:* Reloading deep routes (e.g. `/notebooks/123`) in static file server causes 404.
   - *Resolution:* Configure native host embedded server with fallback routing (`try_files $uri /index.html`).
