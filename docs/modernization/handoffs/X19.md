## Objective

---

## Deliverables & Architectural Changes

### 1. Static Asset Serving & SPA Fallback (`src-tauri/src/static_server.rs`)
- **Embedded Static Server:** Serves pre-built static client assets directly from document root (`runtime/frontend/static` or `.artifacts/static-client-poc`).
- **MIME & Cache Control:** Resolves accurate MIME types (`.html`, `.js`, `.css`, `.json`, `.png`, `.svg`) and sets appropriate `Cache-Control` (`no-cache` for HTML, `public, max-age=31536000, immutable` for static hashed bundles).
- **SPA Dynamic Route Fallback (`try_files $uri /index.html`):** Intercepts non-asset, non-API routes (e.g. `/notebooks/nb-123`, `/settings`, `/podcasts`) and serves `index.html` with HTTP 200 OK and `X-SPA-Fallback: true` header.

### 2. Path Traversal Security Protections
- **Canonical Path Resolution:** Resolves and validates requested paths against the normalized document root.
- **Strict Anti-Traversal Enforcement:** Rejects path traversal sequences (`..`, `%2e%2e`, null bytes `\0`, or path escapes) returning HTTP 403 Forbidden without exposing local filesystem layout.

### 3. API Reverse Proxying (`src-tauri/src/proxy.rs`)
- **Loopback Backend Restriction:** Restricted strictly to target loopback FastAPI backend on `http://127.0.0.1:5055`.
- **Protocol & Header Preservation:** Preserves all standard HTTP methods (`GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `OPTIONS`, `HEAD`), request/response headers, query strings, and status codes (200, 400, 404, 413, 422, 502).

### 4. Upload Payload Limit Enforcement
- **50MB Threshold Check:** Validates multipart upload payload size against maximum threshold of **50 MB** (`52,428,800 bytes`).
- **Status & Error Response:** Rejects oversized uploads with HTTP 413 Payload Too Large and returns HTTP 400 Bad Request for missing multipart file parts.

### 5. Unbuffered SSE Event Streaming Pass-Through
- **Real-Time Token Streaming:** Streams `/api/chat/stream` and `/api/podcasts/progress` without buffer accumulation.
- **Required SSE Headers:** Forces `content-type: text/event-stream`, `cache-control: no-cache`, `connection: keep-alive`, and `x-accel-buffering: no`.
- **Disconnect & Cancellation:** Properly handles client disconnects, terminating upstream streams cleanly without leaking sockets or memory.

### 6. Executable Contract Harness & Test Suite (`src/contracts/native-proxy.ts` & `scripts/tests/test-native-host-proxy.js`)
- **Contract Module:** `src/contracts/native-proxy.ts` provides native proxy and static serving verification logic.
- **Test Suite:** `scripts/tests/test-native-host-proxy.js` validates static serving, path security, reverse proxying, 50MB upload limits, and unbuffered SSE pass-through.
- **Orchestrator Integration:** Integrated into `node scripts/orchestrator/verifier.js` (**13/13 test suites passing**).
