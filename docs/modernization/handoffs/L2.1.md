# L2.1 Handoff: Freeze the native-host contract

## Objective
Define one language-neutral native-host contract so Rust, Go, and C# candidates can be compared fairly. This establishes the required platform responsibilities and compatibility schemas.

## Behaviors Preserved
- Service startup order, logging format, and readiness behaviors.
- Navigation restrictions to loopback and local app origin.
- Port-conflict recovery logic (interactive, app-owned kill only).
- Secrets handling (native secure storage, no leak in logs).

## Explicit Decisions
- Config schema uses JSON Schema v7 format for broad candidate language support.
- Required services are strongly typed in the schema (SurrealDB, API, Worker, Frontend).
- Readiness probe definitions are extensible to HTTP, TCP, or Process variants.
- Strict security isolation parameters (loopback only, strict URL checking) are mandatory requirements in the candidate checklist.

## Rollback Status
