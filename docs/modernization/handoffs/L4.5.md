## Objective
Prove the selected native host (Rust/Tauri) remains safe and recoverable under crashes, stale resources, hostile paths, and unrelated local processes.

## Chaos & Resilience Report

### 1. Crash/Force-Kill/Restart Scenarios
- **Windows Behavior (Passed):** `src-tauri/src/job_object.rs` utilizes `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`. Force-killing the host correctly triggers kernel-level cleanup of all child processes (SurrealDB, API, Worker).
- **Unix Behavior (Exception Tracked):** `src-tauri/src/runner.rs` sets `cmd.process_group(0)`. While this isolates signals, terminating the host with `SIGKILL` leaves child processes orphaned because `PR_SET_PDEATHSIG` is not implemented for Linux.

### 2. Stale-Port Scenarios
- **Finding (Release-Blocking Exception):** The native host in `runner.rs` checks if ports are open (`is_port_open`) and immediately returns an error, failing closed without invoking the interactive port conflict resolution (unlike the TypeScript `port-conflict.ts` behavior). The UX degrades compared to the legacy Electron baseline.

### 3. Path Edge Cases & Manifest Tampering
- **Finding (Security Risk):** `check_missing_files` in `runner.rs` validates existence via `req_path.exists()` but lacks checksum/signature verification. A hostile local process could tamper with the runtime executables, and the host would blindly execute them.

## Security Findings & Resolutions

### 1. Navigation Isolation Policy (Loopback-Only Exposure)
- **Finding (Critical Vulnerability):** `security.rs` checks `url_str.starts_with("http://127.0.0.1:8502")`. This weak prefix matching allows hostile navigation to domains like `http://127.0.0.1:8502.evil.com/` or `http://127.0.0.1:8502@evil.com`.
- **Required Resolution:** Must be patched to parse the URL and explicitly verify `url.domain() == Some("127.0.0.1")` and `url.port() == Some(8502)`.

### 2. Path Traversal & Proxy Integrity
- **Finding (Passed):** `static_server.rs` uses `fs::canonicalize` and ensures resolved paths start with the `normalized_root`. It safely rejects `..`, `%2e%2e`, and null bytes.
- **Finding (Passed):** The proxy in `proxy.rs` properly enforces the 50MB `MAX_UPLOAD_SIZE_BYTES` on all POST routes and `/api/sources/upload`.

### 3. Secret & Path Leakage in Logs
- **Finding (Security Risk):** `runner.rs` blindly pipes stdout/stderr into `logs/{name}.log`. Diagnostic output from child processes containing PII, paths, or bearer tokens is stored in plaintext.
- **Finding (Security Risk):** `runner.rs` currently hardcodes the SurrealDB credentials: `--user root --pass root`.
