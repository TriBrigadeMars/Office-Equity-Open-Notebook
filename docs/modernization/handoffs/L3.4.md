### 4. Selected Native Host Candidate, Contracts, & Security Rules (`L2.1`–`L2.5`)

- **Scorecard & Proof:** `.artifacts/reports/l2_5/native_host_scorecard.json`.
- **Resource Footprint:** Host RSS ~28MB, total app RSS ~132MB (**>70% reduction vs ~438MB Electron baseline**); cold start ~1,380ms (vs ~3,100ms baseline).
- **Contracts & Specs:** `docs/modernization/contracts/host-contract.md`, `docs/modernization/contracts/host-config.schema.json`, `docs/modernization/contracts/candidate-compliance-checklist.md`, & `docs/modernization/NATIVE_HOST_COMPATIBILITY_GUIDE.md`.
- **Security & Process Isolation:**
  - Loopback restriction: Internal HTTP services bind strictly to `127.0.0.1`.
  - Origin isolation: WebView origin restricted strictly to app domain (`http://127.0.0.1:8502` or `tauri://localhost`). `file://` URIs are prohibited.
  - External link delegation: All external web links delegated directly to the OS browser.
  - Child process containment: Windows Job Objects (`JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE`) and Unix `setsid` process groups guarantee zero orphan processes on host termination.
