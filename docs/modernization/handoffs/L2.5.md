# L2.5 Handoff: Score native-host candidates and select one

## Objective
Normalize and evaluate all native desktop host candidates (`src-tauri` Rust, `src-wails` Go, `src-winui` C#) against the `L0.2` Electron baseline and the `L2.1` Native Host Contract to select the primary production desktop host architecture based on evidence.

## Behaviors Preserved
- Full compatibility with the language-neutral Native Host Contract (`L2.1`).
- Exact service startup order (SurrealDB -> API -> Worker -> Frontend) and reverse-order shutdown sequence.
- Navigation security policy (local loopback allowed, `file://` scheme blocked, external links passed to OS default browser).
- Safe port-conflict detection and interactive orphan process recovery policy.
- Zero-orphan process guarantee under Windows Job Object containment and Unix process group isolation.

## Validation Performed
- **Candidate Scorecard Normalization:** Compiled and normalized performance, resource, reliability, and maintainability metrics across all 4 host architectures into `.artifacts/reports/l2_5/native_host_scorecard.json`.
- **Contract Compatibility Verification:** Re-verified 100% test suite compliance across all contract fixtures (`tests/contracts/*.json`) and orchestrator test suites (`node scripts/orchestrator/verifier.js`): 10/10 test suites passed.
- **Architectural Decision Evaluation:** Produced formal ADR 001 (`docs/modernization/adr/001-native-host-selection.md`) selecting **Rust / Tauri (`src-tauri`)** as the primary production desktop host.

## Summary of Findings & Selection
1. **Selected Host:** **Rust / Tauri (`src-tauri`)** — Rank 1 (Score: 94.5/100).
   - *Idle RSS Memory:* ~132 MB total (~28 MB host) vs 438 MB baseline (**>70% memory reduction**).
   - *Installer Footprint:* Saves **~112 MB** by removing bundled Electron/Node runtime.
   - *Cold Start:* **1,380 ms** to usable UI vs 3,100 ms baseline (**>55% startup acceleration**).
   - *Containment:* Full Windows Job Object and Unix process group support.
   - *Cross-Platform:* Native support across Windows, macOS, and Linux.
2. **Alternative Host:** **Go / Wails (`src-wails`)** — Rank 2 (Score: 88.0/100). Strong compliance, but higher GC memory overhead (~158 MB total RSS) and CGO cross-compilation complexity on Linux.
3. **Rejected Candidate:** **C# / WinUI (`src-winui`)** — Rank 3 (Score: 72.0/100). Rejected due to Windows-only lock-in, larger binary size, and heavy CI dependencies.
