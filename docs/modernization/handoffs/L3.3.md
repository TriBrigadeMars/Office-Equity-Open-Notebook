## Objective
Prove the UI can be built and exercised as a static/client application while keeping the existing Next.js standalone server build intact.

---

## Summary of Deliverables

### 1. Parallel Static/Client Build Pipeline (`scripts/build-static-client.js`)
- Assembles a parallel static/client frontend proof of concept build artifact in `.artifacts/static-client-poc/` without modifying or replacing the production Next.js standalone runtime build setup (`scripts/prepare-runtime.js` / `server.js`).
- Generates `index.html` entry point shell with client runtime environment configuration injection (`env-config.js`).
- Produces static route shells (`settings.html`, `models.html`, `podcasts.html`).
- Generates `spa-fallback.json` declaring fallback routes for deep dynamic client paths.

### 2. Client-Safe Configuration & Route Resolution Contract (`src/contracts/static-client.ts`)
- Replaces server-only `process.env.INTERNAL_API_URL` access with explicit client-safe configuration path (`createClientConfig`).
- Implements client route resolution (`resolveClientRoute`) supporting static and dynamic client routes (`/`, `/notebooks/[id]`, `/notes/[id]`, `/sources/[id]`, `/settings`, `/models`, `/podcasts`).
- Generates SPA fallback rules (`generateSpaFallbackRules`) for embedded native host web servers (`try_files $uri /index.html`).
- Dynamic API endpoint resolution (`resolveApiEndpoint`) allowing API calls to point at a configurable host/proxy endpoint without server rewrites.
- Harness evaluator (`runStaticClientPocHarness`) validating static/client proof of concept compliance.

### 3. Canonical Fixtures & Blocker Inventory (`tests/contracts/static-client-cases.json`)
- Dynamic and static route resolution test cases for all 7 UI client routes from L3.1 inventory.
- Recorded Blocker Inventory:
  - **`BLOCKER_001_NO_NODE_REVERSE_PROXY`**: Static client export lacks Node.js Next server rewrite proxy for `/api/*`. Delegated to native host loopback proxy layer in Section 19.
  - **`BLOCKER_002_SPA_DEEP_ROUTE_FALLBACK`**: Direct refresh on deep dynamic routes (e.g., `/notebooks/123`) requires static server SPA fallback to `/index.html`.
  - **`BLOCKER_003_SERVER_ENV_ELIMINATION`**: Server-only `process.env` dependencies replaced with client-safe `window.__CONFIG__` or `NEXT_PUBLIC_API_URL`.

### 4. Executable Mechanical Regression Test (`scripts/tests/test-static-client-poc.js`)
- Executable test runner integrated with `node scripts/orchestrator/verifier.js`.
- Verifies parallel static/client build artifact generation.
- Verifies 11/11 contract harness assertions pass cleanly.
- Confirms dynamic client route resolution and SPA fallback rules.
- Validates configurable host/proxy endpoint resolution (`/api/chat/stream`, `/api/health`).
- Confirms existing Next.js standalone build target remains intact.

### 5. Snapshot Report Deliverable (`.artifacts/reports/l3_3/static_client_poc.json`)
- Frozen snapshot deliverable recording the static client POC verification results, route counts, SPA rules, and blocker inventory.
